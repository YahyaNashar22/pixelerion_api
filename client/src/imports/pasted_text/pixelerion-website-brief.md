Create a premium, modern, dark-themed website for a software development company called Pixelerion.

The website should feel like a high-end creative technology studio specializing in custom websites, web applications, mobile applications, software systems, UI/UX, and ongoing technical support.

Brand Identity

Company name: Pixelerion

Pixelerion’s logo/brand colors are inspired by the four Google colors:

* Blue
* Red
* Yellow
* Green

Do NOT make the website look like Google.

Use these colors intelligently as subtle accents throughout the interface:

* glowing particles
* gradient borders
* small highlights
* animated lines
* hover states
* 3D lighting
* status indicators

The main website theme should remain very dark:

* near-black background
* dark charcoal surfaces
* subtle glassmorphism
* soft reflections
* tasteful colored glow

The overall visual direction should feel like a combination of:

* premium software agency
* futuristic digital studio
* interactive 3D experience
* minimal SaaS product
* high-end developer portfolio

Avoid generic corporate templates.

3D HERO EXPERIENCE

The landing page must include a sophisticated interactive 3D animation.

Do NOT use a generic rotating globe.

Create an abstract futuristic digital environment representing software development.

Possible concept:

A floating 3D Pixelerion core made from multiple interconnected glass or metallic blocks/pixels.

Each group can subtly represent:

* Web
* Mobile
* Cloud
* Design
* APIs
* Infrastructure

Small luminous particles and connection lines should move between the blocks.

Use Pixelerion’s blue, red, yellow and green colors as the lighting sources.

The animation should:

* react subtly to mouse movement
* have slow idle movement
* respond to scrolling
* change camera position slightly while scrolling
* use depth and atmospheric lighting
* remain elegant and not distracting

The object can slowly deconstruct/reconstruct as the user moves through the hero.

Use:

* Three.js / React Three Fiber
* GSAP
* ScrollTrigger

where appropriate.

Performance is important.

Use lazy loading and reduced effects on mobile.

DESIGN SYSTEM

Use:

* dark backgrounds
* large typography
* clean spacing
* rounded cards
* subtle glass surfaces
* thin borders
* soft shadows
* minimal gradients

Suggested typography:

Inter, Manrope, Geist, or Satoshi

Headings should be large and bold.

Avoid excessive neon cyberpunk effects.

Pixelerion’s four colors should appear primarily through lighting, gradients, indicators and micro-interactions.

Animations should feel smooth and expensive.

Use:

* GSAP
* Framer Motion
* Three.js / React Three Fiber

⸻

RESPONSIVENESS

Design desktop-first but make the entire system fully responsive.

Desktop should feel spacious and cinematic.

Tablet should simplify the 3D scenes.

Mobile should prioritize performance and usability and reduce particle counts and intensive animation.
